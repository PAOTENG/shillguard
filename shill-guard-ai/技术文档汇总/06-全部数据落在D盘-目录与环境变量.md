# 全部数据落在 D 盘（统一挂到 `D:\Environment`）

> 约束：Hermes / Pi / Benchmark 缓存等**不得**落在 `C:\Users\oops\.hermes` 等用户目录。  
> 运行时家目录与 Anaconda/JDK 一样，统一放在 **`D:\Environment`** 下。  
> 做法：用官方环境变量改「家目录」，再用用户环境变量或启动脚本保证每次生效。

---

## 1. 推荐布局

```text
D:\project\
├── shill-guard\                 # Java（已有）
├── shill-guard-frontend\        # 前端（已有）
└── shill-guard-ai\              # AI 业务仓（已有）
    ├── app\
    ├── examples\pi_governance_agent\
    ├── eval\shillguard_agent_eval\
    └── eval\public_bench\

D:\Environment\                  # ★ 本机「环境根」（已有 Anaconda、JAVA 等）
├── Anaconda\                    # 已有
├── JAVA17\                      # 已有（示例）
├── Maven3.9.16\                 # 已有（示例）
└── shillguard-runtime\          # ★ 新建：Agent 运行时状态（不进 git）
    ├── hermes\                  # = HERMES_HOME
    │   ├── config.yaml
    │   ├── .env
    │   ├── kanban.db
    │   ├── profiles\
    │   ├── sessions\
    │   ├── memories\
    │   ├── skills\
    │   └── logs\
    ├── pi\
    │   └── agent\               # = PI_CODING_AGENT_DIR（必须含 \agent）
    │       ├── auth.json
    │       ├── settings.json
    │       ├── models.json
    │       └── sessions\
    ├── bench-cache\
    │   ├── swebench\
    │   └── agentbench\
    ├── npm-global\              # 可选：npm 全局前缀
    └── tmp\                     # 可选：TEMP/TMP

D:\app\                          # 已有：Node、Git、Cursor 等安装目录（保持）
```

原则：

- **代码与领域 Eval** → `D:\project\shill-guard-ai`
- **Hermes / Pi / bench 缓存** → `D:\Environment\shillguard-runtime\...`
- **Python** → 已有 `D:\Environment\Anaconda\envs\agent\python.exe`
- **不要**再用 `C:\Users\oops\.hermes`、`C:\Users\oops\.pi`

## 2. Hermes：`HERMES_HOME`

官方读环境变量 **`HERMES_HOME`**；未设置才用 `~\.hermes`（C 盘）。

### 2.1 一次性准备（cmd，任意目录可执行）

```bat
mkdir D:\Environment\shillguard-runtime\hermes
setx HERMES_HOME "D:\Environment\shillguard-runtime\hermes"
```

`setx` 之后**必须新开 cmd**。

验证：

```bat
echo %HERMES_HOME%
hermes config path
```

应看到 `D:\Environment\shillguard-runtime\hermes`。

### 2.2 若 C 盘已有旧 `.hermes`

```bat
xcopy /E /I /Y "%USERPROFILE%\.hermes\*" "D:\Environment\shillguard-runtime\hermes\"
setx HERMES_HOME "D:\Environment\shillguard-runtime\hermes"
```

### 2.3 启动脚本双保险

```bat
@echo off
set HERMES_HOME=D:\Environment\shillguard-runtime\hermes
set PI_CODING_AGENT_DIR=D:\Environment\shillguard-runtime\pi\agent
cd /d D:\project\shill-guard-ai
hermes %*
```

---

## 3. Pi：`PI_CODING_AGENT_DIR`

必须指向 **`...\pi\agent` 这一层**（不要只指到 `...\pi`）。

```bat
mkdir D:\Environment\shillguard-runtime\pi\agent
setx PI_CODING_AGENT_DIR "D:\Environment\shillguard-runtime\pi\agent"
setx PI_CODING_AGENT_SESSION_DIR "D:\Environment\shillguard-runtime\pi\agent\sessions"
```

项目内还可有 `D:\project\shill-guard-ai\.pi\`（已在 D: 仓内）。

---

## 4. Benchmark 缓存

```bat
mkdir D:\Environment\shillguard-runtime\bench-cache\swebench
mkdir D:\Environment\shillguard-runtime\bench-cache\agentbench
```

`eval/public_bench/**/TASKS.md` 与 Docker volume 均指向上述路径。

## 5. 用户环境变量一览

| 变量名 | 值 |
|--------|-----|
| `HERMES_HOME` | `D:\Environment\shillguard-runtime\hermes` |
| `PI_CODING_AGENT_DIR` | `D:\Environment\shillguard-runtime\pi\agent` |
| `PI_CODING_AGENT_SESSION_DIR` | `D:\Environment\shillguard-runtime\pi\agent\sessions` |
| （可选）`TEMP` / `TMP` | `D:\Environment\shillguard-runtime\tmp` |

可选 npm 全局：

```bat
mkdir D:\Environment\shillguard-runtime\npm-global
npm config set prefix "D:\Environment\shillguard-runtime\npm-global"
```

（再把该 `prefix` 下的路径加入用户 PATH。）

改完后**重开所有终端 / IDE**。

---

## 6. 一次跑完的 cmd（复制用）

在任意目录打开 cmd 即可（建议先 `cd /d D:\project\shill-guard-ai`）：

```bat
mkdir D:\Environment\shillguard-runtime\hermes
mkdir D:\Environment\shillguard-runtime\pi\agent
mkdir D:\Environment\shillguard-runtime\bench-cache\swebench
mkdir D:\Environment\shillguard-runtime\bench-cache\agentbench
mkdir D:\Environment\shillguard-runtime\tmp

setx HERMES_HOME "D:\Environment\shillguard-runtime\hermes"
setx PI_CODING_AGENT_DIR "D:\Environment\shillguard-runtime\pi\agent"
setx PI_CODING_AGENT_SESSION_DIR "D:\Environment\shillguard-runtime\pi\agent\sessions"
```

然后**关闭窗口，新开 cmd**，执行：

```bat
echo %HERMES_HOME%
echo %PI_CODING_AGENT_DIR%
dir D:\Environment\shillguard-runtime
```

---

## 7. 自检

跑过 Hermes / Pi 后应满足：

- 文件出现在 `D:\Environment\shillguard-runtime\hermes` / `...\pi\agent`
- **没有**继续写入 `C:\Users\oops\.hermes` / `C:\Users\oops\.pi`

说明：`USERPROFILE` 仍在 C: 是系统行为；本方案保证 **Agent 状态与评测缓存** 在 `D:\Environment`。

## 8. 修订对照

| 旧路径（已废弃） | 新路径 |
|------------------|--------|
| `D:\shillguard-runtime\...` | **`D:\Environment\shillguard-runtime\...`** |
| `C:\Users\oops\.hermes` | `HERMES_HOME` → Environment 下 |
| `C:\Users\oops\.pi\agent` | `PI_CODING_AGENT_DIR` → Environment 下 |
