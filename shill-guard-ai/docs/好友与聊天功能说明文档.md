# ShillGuard 好友与聊天功能说明文档

## 一、概念说明

本平台没有独立的"好友"表。好友关系就是关注关系：你关注了谁，谁就在你的好友列表里。好友列表即关注列表，取消关注即删除好友。

## 二、创建好友（关注用户）

### 操作步骤

1. 打开任意用户的个人主页（通过帖子作者头像、搜索用户、或粉丝列表进入）
2. 点击页面上的「+ 关注」按钮
3. 按钮变为「已关注」，关注成功

### 其他入口

- 帖子详情页：点击作者名字旁的关注按钮
- 搜索结果：在用户搜索结果中直接关注

### 注意

- 不能关注自己
- 被关注的用户必须是正常状态（未被禁言）
- 重复关注不会报错，系统自动忽略

## 三、删除好友（取消关注）

### 入口一：聊天界面

1. 进入好友列表页面（侧边栏「好友」）
2. 点击某个好友进入聊天界面
3. 聊天顶部右侧有「已关注」按钮，点击它
4. 弹出确认框：「确定取消关注该用户吗？取消后将无法发送消息，需重新关注才能继续聊天。」
5. 点击「确定取消关注」

### 入口二：个人资料页

1. 进入自己的个人资料页（侧边栏头像或「我的」）
2. 切换到「我的关注」标签页
3. 每个关注用户右侧有「取消关注」按钮，点击它
4. 弹出确认框：「确定取消关注该用户吗？取消后将无法在聊天中发送消息。」
5. 点击「确定取消关注」，该用户立即从列表中消失

### 入口三：对方个人主页

1. 进入对方的个人主页
2. 原来的「已关注」按钮，点击变为「+ 关注」
3. 取消关注完成

## 四、与好友聊天

### 进入聊天

1. 点击侧边栏的「好友」入口
2. 好友列表显示所有你关注的用户，按最近聊天时间排序
3. 每个好友显示头像、昵称、最后一条消息预览、时间、未读红点
4. 点击某个好友进入聊天界面

### 发送消息

聊天界面支持三种消息类型：

- 文本消息：在底部输入框输入文字，按回车键或点击「发送」按钮
- 表情消息：点击表情按钮，选择 Emoji 或自定义表情图发送
- 文件消息：点击文件按钮上传文件（支持压缩包和常见文档，单个文件不超过50MB）

### 消息接收

- 对方在线时，消息通过 WebSocket 实时推送，对方立即收到
- 对方不在线时，消息存入数据库，对方下次进入聊天界面时拉取历史消息并显示未读红点

### 消息已读

- 进入聊天界面时，对方发来的消息自动标记为已读
- 未读消息数量在好友列表中以红点数字显示

## 五、聊天权限规则

聊天权限取决于双方的关注关系，分三种情况：

### 情况一：互相关注

- 你关注了对方，对方也关注了你
- 双方可以无限制地发送消息

### 情况二：单向关注（你关注对方，对方没关注你）

- 你可以给对方发消息，但只能发1条
- 在对方回复你之前，你不能继续发送
- 对方回复后，你即可继续发送消息
- 如果对方始终不回复，你只能发1条

### 情况三：未关注（你取消了关注，或从未关注过对方）

- 你不能给对方发送任何消息
- 输入框变为灰色不可点击，上方显示提示：「你已取消关注对方，无法发送消息。重新关注后即可继续聊天。」
- 你需要重新关注对方才能恢复聊天权限

### 特殊说明

- 对方给你发消息不受你关注状态的影响。只要对方关注了你，对方就可以按上述规则给你发消息
- 取消关注后，历史聊天记录仍然保留，你重新关注后可以看到之前的记录并继续聊天
- 不能给自己发消息

## 六、完整操作流程示例

### 场景：用户A添加用户B为好友并聊天

1. 用户A打开用户B的个人主页，点击「+ 关注」
2. 用户A进入好友列表，看到用户B出现在列表中
3. 用户A点击用户B进入聊天界面
4. 用户A输入消息「你好」，点击发送
5. 用户B在线，收到实时消息推送
6. 因为用户B没有关注用户A，用户A暂时不能再发消息（等待回复）
7. 用户B回复「你好呀」
8. 用户A现在可以继续发送消息了

### 场景：用户A取消关注用户B

1. 用户A在聊天界面点击右上角「已关注」按钮
2. 确认取消关注
3. 聊天界面输入框变灰，显示提示条
4. 用户A无法再给用户B发消息
5. 用户B如果关注了用户A，仍然可以给用户A发消息
6. 用户A重新点击「+ 关注」按钮恢复关注
7. 输入框恢复可用，可以继续聊天

### 场景：互相关注的好友无限制聊天

1. 用户A关注用户B
2. 用户B关注用户A
3. 双方在好友列表中都能看到对方
4. 双方可以随时发送任意数量的消息，没有限制
