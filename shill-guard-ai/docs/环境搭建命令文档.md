# ShillGuard AI —— 环境搭建命令文档

> 按本文档逐条执行即可完成开发环境搭建。
> 操作系统：Windows 11 + PowerShell（Linux/macOS 把激活命令换成 source 即可）

---

## 〇、Python 版本选择

**结论：用 Python 3.12（2026 LangGraph 生产开发主流版本）。**

| 版本 | 状态 | 说明 |
|---|---|---|
| 3.11 | ✅ 可用 | 生态最广，LangGraph 官方 CLI 默认 |
| **3.12** | ✅ **推荐** | 生产部署官方镜像 `langchain/langgraph-api:3.12` 就是它 |
| 3.13 | ⚠️ 谨慎 | 可用但部分原生依赖（PyO3 系）滞后 |
| 3.14 | ❌ 别用 | jsonschema-rs/PyO3 链尚未跟上，langgraph-cli 装不上 |

> 你当前使用 conda 环境 `agent`，Python 3.12.13，符合推荐。

检查当前 Python：
```powershell
python --version
# 期望: Python 3.12.13
```

## 二、激活 conda 虚拟环境

> 虚拟环境 `agent` 已创建好（Python 3.12.13），只需激活。

```powershell
conda activate agent
```

激活后命令行前缀会出现 `(agent)`。后续所有 pip 命令都在激活状态下执行。

> 如果误删了要重建：
> ```powershell
> conda create -n agent python=3.12.13
> conda activate agent
> ```

> 建议用 pip 装依赖（不要用 conda install 装 AI 类包，conda 仓库版本滞后且依赖解析慢）：
> ```powershell
> # 确保 conda 环境里 pip 是最新的
> python -m pip install --upgrade pip
> ```

## 三、安装依赖包（按层分组）

### 1. Web / 接入层（FastAPI）
```powershell
pip install fastapi "uvicorn[standard]" pydantic-settings python-dotenv httpx
```

### 2. 编排层（LangGraph + LangChain 模型集成）
```powershell
pip install langgraph langchain-core langchain-openai langchain-community
```
> 说明：
> - `langchain-openai` 用 OpenAI 兼容协议接 **百炼 / DeepSeek / 通义**（配 base_url 即可），也接 OpenAI 官方。
> - `langchain-community` 提供 DashScope 等社区集成。

### 3. 模型层 —— Embedding & Reranker
```powershell
# 阿里百炼官方 SDK（embedding / rerank / qwen-vl 都走它）
pip install dashscope

# 自部署 BGE-M3 / BGE-reranker-v2 时用（可选，隐私场景备用）
pip install sentence-transformers
```

### 4. 向量库 —— Qdrant
```powershell
pip install qdrant-client
```

### 5. 图库 + GraphRAG —— Neo4j
```powershell
pip install neo4j "neo4j-graphrag[qdrant]"
```
> `neo4j-graphrag[qdrant]` 会带上 qdrant 集成，提供 `QdrantNeo4jRetriever`。

### 6. 工具协议 —— MCP
```powershell
pip install fastmcp
```

### 7. 可观测 —— Langfuse（LangGraph 自动 trace）
```powershell
pip install langfuse
```
> LangSmith 不用装包：LangChain 已内置集成，只需设环境变量 `LANGSMITH_TRACING=true` + `LANGSMITH_API_KEY`。二选一即可。

### 8. 评测 —— RAGAS
```powershell
pip install ragas
```

### 9. 生产状态持久化（可选，先跳过，等需要时再装）
```powershell
# 用 Postgres 做 LangGraph checkpointer 时才需要
pip install langgraph-checkpoint-postgres psycopg2-binary
```

### 10. 开发辅助（可选）
```powershell
# LangGraph Studio 可视化调试图（可选，体验用）
pip install "langgraph-cli[inmem]"

# 代码格式化（可选）
pip install ruff
```

## 四、一次性装完（懒人版）

> 先确认已 `conda activate agent`，且在项目目录 `d:\Projects\shill-guard-ai` 下。

把上面必要项合并成一条，复制即装：

```powershell
pip install ^
  fastapi "uvicorn[standard]" pydantic-settings python-dotenv httpx ^
  langgraph langchain-core langchain-openai langchain-community ^
  dashscope sentence-transformers ^
  qdrant-client ^
  neo4j "neo4j-graphrag[qdrant]" ^
  fastmcp ^
  langfuse ^
  ragas
```

Linux/macOS bash 版（把 `^` 换成 `\`）：
```bash
pip install \
  fastapi "uvicorn[standard]" pydantic-settings python-dotenv httpx \
  langgraph langchain-core langchain-openai langchain-community \
  dashscope sentence-transformers \
  qdrant-client \
  neo4j "neo4j-graphrag[qdrant]" \
  fastmcp \
  langfuse \
  ragas
```

## 六、配置环境变量

```powershell
copy .env.example .env
```
然后编辑 `.env`，至少填：
```env
# 百炼（阿里云控制台 -> DashScope/百炼 -> API-KEY）
LLM_API_KEY=sk-你的百炼key
LLM_MODEL=qwen-plus          # 或 qwen-max / qwen-turbo
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1

# 百炼 embedding 单独用 DashScope SDK，可在代码里用 DASHSCOPE_API_KEY
DASHSCOPE_API_KEY=sk-你的百炼key

# 向量库 / 图库（Docker 起来后填）
QDRANT_URL=http://192.168.150.101:6333
NEO4J_URL=bolt://192.168.150.101:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=你的neo4j密码

# 可观测（可选，开发建议开）
LANGFUSE_PUBLIC_KEY=
LANGFUSE_SECRET_KEY=
LANGFUSE_HOST=https://cloud.langfuse.com
```

## 九、常见踩坑提示

1. **Python 版本**：别用 3.14，3.13 谨慎，3.12 最稳。
2. **`neo4j-graphrag[qdrant]` 的引号**：PowerShell 里必须带引号，否则 `[qdrant]` 会被当通配符解析报错。
3. **百炼 embedding 两种接法**：
   - OpenAI 兼容（简单）：`OpenAIEmbeddings(base_url="https://dashscope.aliyuncs.com/compatible-mode/v1")`
   - DashScope SDK（功能全，含 rerank）：`dashscope` 包
4. **sentence-transformers 较大**：会拉 torch（几百 MB），网络慢可先不装，等确定要自部署 BGE 再装。
5. **pip 慢**：换国内源 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包名>`。
6. **依赖装完先跑 `python -c "import ..."` 验证**，再启动服务，避免运行时才发现缺包。
