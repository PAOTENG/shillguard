五、为什么你之前的 history_router.py 取不到数据
你写的：

messages_raw = checkpoint_data.get("channel_values", {}).get("messages", [])
channel_values 里有 doc_context、rag_context，但没有 messages 键（或值为 None）
.get("messages", []) 拿到的是 None 或 []
所以 messages_raw 永远是空的 → 返回空列表 → 前端显示"未命名对话"
消息在 checkpoint_blobs 表里，是 msgpack 二进制，里面是 LangChain 类对象序列化格式，用普通 SQL + JSON 解析根本读不出来。必须用 LangGraph 的 graph.aget_state(config)，它会自动：

从 checkpoints 表取最新快照
用快照里的 version 去 checkpoint_blobs 表取对应的 blob
用 msgpack + LangChain 反序列化器把 blob 还原成 HumanMessage/AIMessage 对象
塞进 state.values["messages"] 返回给你
