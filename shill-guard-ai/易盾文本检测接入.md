# 易盾文本检测接入

> 本文档记录 ShillGuard 项目接入**网易易盾（Yidun）商业文本审核 API** 的完整过程，包括控制台开通、代码改动、配置项、级联架构、联调方式，以及当前**试用审核中导致 401** 的问题说明与临时应对方案。

---

## 一、背景与目标

### 1.1 为什么接易盾

内容审核级联（Cascade）原架构为：

```
T1-黑名单 → T1-白名单 → T2-加权 → T3-LLM（完整 LangGraph 链路）
```

T1/T2 均为本地确定性规则，对**语义级违规**（阴阳怪气、隐晦辱骂、复杂语境）拦截能力有限，绝大多数 case 仍会落到 T3，LLM 调用占比高。

接入易盾后，在 T1 黑名单之后插入 **T2-api** 层，用商业 API 做语义检测：

- **高置信违规**（score ≥ 0.85）→ 模板证据，**0 次 LLM**
- **灰区** → 继续走白名单 / T3 LLM
- **API 失败** → fail-open，不误封，退回后续级联

### 1.2 选型结论

| 方案 | 工期 | 简历价值 | 结论 |
|------|------|----------|------|
| 自训二分类器 | 3~5 天 | 高（可写模型训练） | 时间紧时备选 |
| **网易易盾商业 API** | **1~2 天** | 中（工程集成 + 成本优化） | **已采用** |

## 二、易盾控制台开通流程

### 2.1 创建产品

1. 登录 [网易易盾控制台](https://dun.163.com/)
2. 创建产品 → 选择 **AI 内容审核**
3. 行业选择：**社交 / 社区**（与 ShillGuard 场景匹配）

### 2.2 申请试用

1. 在产品页申请试用（默认 7 天）
2. 等待商务/系统审核通过

> **当前状态（2026-07-10）**：试用仍在**审核中**，密钥已生成但接口返回 401，暂无法完成真 API 联调。配置信息本身已核对无误，根因是**试用未开通**，非代码或参数抄错。

### 2.3 获取三个关键凭证

审核通过后，在控制台按以下路径获取（**三者必须属于同一产品**）：

| 凭证 | 获取路径 | 说明 |
|------|----------|------|
| `secretId` | 服务管理 → 查看产品密钥 | 产品级密钥 ID |
| `secretKey` | 同上 | 与 secretId 配对，**不可泄露** |
| `businessId` | 服务管理 → **文本检测** → 业务列表 → 业务 ID | **不是产品 ID**，是文本检测业务 ID（32 位 hex） |

### 2.4 易盾 API 端点（勿用错）

| 用途 | URL | 说明 |
|------|-----|------|
| **单次同步文本检测（T2 用）** | `http://as.dun.163.com/v5/text/check` | ✅ 正确 |
| OpenAPI 网关 | `https://openapi.dun.163.com/...` | ❌ 不是本场景 |
| 异步批量检测 | `.../async-batch-check` | ❌ 级联需要同步结果 |

接口版本：官方 demo 默认 `v5.2`，本项目配置为 `v5.3`（与控制台开通版本一致即可）。

### 3.3 级联架构（接入后）

```
T1-blacklist  (<1ms)   → 铁证违规，模板证据
        ↓
T2-api        (~300ms)  → 易盾商业 API 语义检测
        ↓ fail-open / 灰区
T1-whitelist  (<1ms)   → 铁证正常
        ↓
T3-LLM        (1-30s)  → 完整 LangGraph 链路
```

**T2-api 决策逻辑**（`cascade.py`）：

| 条件 | 行为 |
|------|------|
| `risk_score >= cascade_api_block_threshold`（默认 0.85） | `clear_violation`，`filter_tier=T2-api`，0 LLM |
| `risk_score <= cascade_api_pass_threshold`（默认 0.15，第一期建议保持 0 即跳过） | `clear_normal` |
| 灰区（0.15 ~ 0.85） | 不 return，继续白名单 / T3 |
| `api_result.error` 非空 | **fail-open**，打印日志后继续级联 |

**易盾 suggestion 映射**（`yidun.py`）：

| 易盾 suggestion | 含义 | 映射 risk_score |
|-----------------|------|-----------------|
| 0 | 通过 | 0.05 |
| 1 | 嫌疑 | 0.55（可按 riskLevel 微调） |
| 2 | 不通过 | 0.92 |

## 四、环境配置（`.env`）

在项目根目录 `.env` 中增加以下项（值为占位符，实际填写控制台复制的凭证）：

```env
# T2 商业 API 开关
CASCADE_API_ENABLED=true
CASCADE_API_MOCK=false
CASCADE_API_PROVIDER=yidun
CASCADE_API_TIMEOUT_MS=800
CASCADE_API_BLOCK_THRESHOLD=0.85
CASCADE_API_PASS_THRESHOLD=0.15

# 网易易盾凭证（试用审核通过后填写）
YIDUN_SECRET_ID=你的secretId
YIDUN_SECRET_KEY=你的secretKey
YIDUN_BUSINESS_ID=你的文本检测业务ID
YIDUN_API_URL=http://as.dun.163.com/v5/text/check
YIDUN_API_VERSION=v5.3
```

**注意**：

- `secretId` / `secretKey` / `businessId` 必须来自**同一产品**下的文本检测业务
- `businessId` 是「文本检测 → 业务列表」里的业务 ID，不是产品编号
- 密钥只写在 `.env`，不要提交到 Git

## 六、当前问题：试用审核中导致 401

### 6.1 现象

开启 `CASCADE_API_ENABLED=true` 跑 `cascade_eval.py` 或线上服务时，每条内容日志类似：

```
[级联-T2API] 调用失败 fail-open: yidun code=401, msg=未经授权，请检查secretId或者businessId是否正确，若试用到期请联系商务
[级联] 退回LLM: 长度=30, 加权=0.00
```

### 6.2 排查过程（已确认非代码问题）

| 检查项 | 结果 |
|--------|------|
| API 地址 `http://as.dun.163.com/v5/text/check` | 可连通，返回 JSON |
| 签名算法（参数 ASCII 排序 + MD5） | 与[官方 Python demo](https://gitee.com/netease_yidun/antispam-python-demo) 一致 |
| 签名错误时的返回码 | 应为 **410**，实际为 **401** → 排除签名 bug |
| `v5.2` / `v5.3` 版本对比 | 均返回 401；版本不匹配一般为 **415** |
| `.env` 中 secretId / businessId / URL | 与控制台一致，格式正确 |
| 级联 fail-open | 行为正确，API 失败后继续白名单 → T3，**不会误封** |

### 6.3 根因

**易盾试用仍在审核中，业务未正式开通。** 官方文档对 401 的说明：

> 产品/业务无效或过期；试用到期需联系商务；请检查 secretId、businessId 是否正确。

本项目凭证配置无误，401 原因为**试用未生效**，待商务审核通过后即可恢复。

### 6.4 试用通过后的验收步骤

1. 控制台确认试用状态为「已开通 / 使用中」
2. 重新复制 `secretId`、`secretKey`、`businessId` 到 `.env`（防止审核期间密钥轮换）
3. 运行 `python scripts\test_yidun.py 测试文本`，确认 `code=200`
4. 设置 `CASCADE_API_MOCK=false`，跑 `python loadtest\cascade_eval.py` 观察 T2-api 命中率
5. 可选：跑 `python loadtest\ragas_eval.py` 对比 API 开/关时的 LLM 调用与 token 节省

## 七、试用未通过期间的临时方案

| 场景 | 推荐配置 |
|------|----------|
| 跑级联基线（不关心 T2-api） | `CASCADE_API_ENABLED=false` 或 `--no-api` |
| 验证 T2-api 分支逻辑（不调真 API） | `CASCADE_API_MOCK=true` + `CASCADE_API_ENABLED=true` |
| 线上服务（避免 401 日志刷屏） | 暂时 `CASCADE_API_ENABLED=false`，等试用通过再开 |

fail-open 保证即使 401 也不影响审核正确性，只是**暂时无法获得 T2-api 的 LLM 节省收益**。

## 八、易盾返回码速查

| code | 含义 | 处理建议 |
|------|------|----------|
| 200 | 成功 | 正常解析 antispam 结果 |
| 400 | 缺少 secretId 或 businessId | 检查请求参数 |
| **401** | **产品/业务无效或试用过期** | **当前问题：等试用审核** |
| 402 | 业务未上线 | 控制台上线业务 |
| 405 | 参数错误 | 检查 timestamp、nonce 等 |
| 410 | 签名验证失败 | 检查 secretKey 与签名算法 |
| 411 | 请求频率超限 | 降 QPS 或联系商务 |
| 413 | 试用总量超限 | 联系商务或切正式套餐 |
| 415 | 版本与接口不匹配 | 调整 `YIDUN_API_VERSION` |
